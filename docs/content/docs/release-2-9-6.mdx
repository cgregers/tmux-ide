Version `2.9.6` focuses on shared terminal delivery, resizing and discovery
between the terminal app and the native client.

## Platform support

Intel Macs are no longer supported. `2.9.6` ships bundled tmux and the compiled
app runtime for macOS on Apple Silicon and glibc Linux on x64 and ARM64. The
installer refuses Intel Macs. Existing Intel installations keep working on
`2.9.5`; stay on that version rather than updating.

## Terminal and daemon changes

- Preserve terminal delivery order and public workspace identity when controllers disconnect or runtimes change.
- Authorize pane resizing against current tmux layout and ownership, including guarded native split resizing.
- Share Home and machine discovery between terminal and native clients, with polling and subscription fixes that let pending observations finish.
- Improve empty-server discovery and exact-agent admission while preserving existing tmux sessions.

These changes concern shared daemon and terminal behavior. They do not claim
complete TUI parity, zero bugs or a measured performance improvement.

## Separate native alpha

The repository includes the opt-in [native macOS alpha](/docs/native-alpha)
source and distribution tooling. The native app remains outside the npm runtime
package: installing or updating the CLI does not install or update the app.
The published native alpha's documented CLI compatibility remains 2.9.5 until
qualification establishes a newer pairing.

The former web/Electron clients are retired. Their shared qualification fixtures
now live independently of renderer packages; the documentation website remains
supported.

## Before updating

Existing tmux sessions are preserved; do not kill servers as an upgrade step.
Native and CLI versions have separate installation and rollback paths.
